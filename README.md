# 📧 Spam Email Classifier 

## About the Project
This is a Machine Learning project that classifies emails as **Spam ❌** or **Not Spam ✅** using Natural Language Processing techniques.

---

## Tech Stack
- Python 
- Scikit-learn 
- Pandas 
- TF-IDF Vectorization

---

## Features
- Text preprocessing
- Feature extraction using TF-IDF
- Naive Bayes classification
- Real-time prediction
