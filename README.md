# 📧 Spam Email Classifier (ML Project)

## 🚀 Overview
A machine learning project that classifies emails as Spam or Not Spam using Natural Language Processing.

## 🧠 Tech Stack
- Python
- Scikit-learn
- Pandas
- NLP (TF-IDF)

## ⚙️ How it Works
1. Text preprocessing
2. TF-IDF feature extraction
3. Naive Bayes model training
4. Prediction on new emails

## 📂 Project Structure
src/ → code  
model/ → trained ML model  
requirements.txt → dependencies  

## ▶️ How to Run
```bash
pip install -r requirements.txt
cd src
python train.py
python predict.py
